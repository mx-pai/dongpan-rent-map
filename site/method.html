找房需要同时回答两个问题：具体房间是否适合居住，从实际门址到办公楼是否满足通勤时间，地图点位用来定位和测路，租赁及住宿页面用来核对房型、面积、价格与条件，页面把两类信息通过 POI、地址和原始来源关联起来

从公开资料到可筛选的地图

  1. 地点核验高德 POI ID、院号、门店地址
  2. 测量通勤步行、骑行、地铁与分段接驳
  3. 核对租住信息房型、月租、卫浴、押付及来源日期
  4. 发布前校验时长加总、信息状态、地图浏览器交互
  5. Actions 发布推送 main 后构建 GitHub Pages

小区优先使用住宅区 POI，酒店和公寓按门店地址核对，同名异店、同楼不同经营者、覆盖多个分区的小区会在点位备注中说明，找到具体房号后应从可出入的大门重新测量

通勤的三种时间口径

直接步行或自行车

住处 → 东畔 A 座

步行 ≤30 分钟
自行车 ≤20 分钟

读取高德路线页面对应的 duration，使用住宅点位或门店坐标计算，范围由已测点位表示

地铁自动全程

住处 → 两端接驳与地铁 → A 座

全程 ≤20 分钟

保留全程规划时长，公共交通方案筛选为地铁，公交及出租车不混入此口径，规划时刻单列在数据中

分段测量

到站接驳 + 入口到出口地铁 + 到楼步行

分段加总 ≤20 分钟

地铁段保留站内步行、换乘和预计等车，比较步行或骑行接驳，页面同时展示按秒合计与各段向上取整后的分钟合计

按用户最初的“地铁乘车20分钟”口径，页面还可以筛选地铁线路段 ≤20 分钟的点位，此时间取地铁线路的运行时长之和，接驳时间另列，申请时应上传地图 App 各测距方式页面截图，以各段页面显示的时长相加为准

慧忠北里分段实例

骑行到安立路 A1 口 222秒 + 地铁入口到北沙滩 A 西北口 627秒 + 步行到 A 座 229秒 = 1078秒，约18.0分钟，各段分别向上取整后为4 + 11 + 4 = 19分钟

地图交互、复制与高德打开

地图使用 Leaflet 处理惯性拖动、滚轮与双指缩放，标记大小保持固定，密集点位通过聚合圆圈展开，选中地点与列表、详情和路线同步，备选地点保存在当前浏览器本地，可通过地点分享链接在其他设备查看

底图通过高德静态地图 API 采集，并按相同 GCJ-02 坐标建立本地分块，放大时按需加载详细底图，图片覆盖本次已测区域，路线折线使用高德接口返回的坐标，标记碰撞后的展开位置以连接线指回原坐标，选择具体楼栋大门后应重新测量

详情支持复制地点全文、名称、地址、GCJ-02 经纬度、地点分享链接和通勤路线，清单可复制为含地址的文本，或导出 CSV 与完整 JSON，CSV 的经度在前、纬度在后

“带到高德”使用官方 URI API，传递地点坐标、起终点和出行方式，手机端会尝试打开高德 App，电脑端可打开高德网页，骑行 URI 按官方规则在移动端使用，实际能否唤起 App 取决于浏览器及客户端安装状态

分段通勤分别提供到站接驳、入口到出口的地铁规划、出口到办公地点三条链接，可逐段核对交通方式并截图，地铁规划打开后需选择对应的地铁方案，高德按打开时的条件重新规划，申请按各段页面显示时长加总

备选地点优先生成地点组，尚未加入备选时使用当前筛选清单，官方多点 URI 每组上限 10 点，页面每组放入 9 个住处和 A 座，自动按顺序分组，地点组在高德展示，收藏在高德中确认

参考高德官方 单点标注、多点标注、路径规划 URI、静态地图 API，地图交互库为 Leaflet 1.9.4 与 Leaflet.markercluster 1.5.3，许可证随源码保留

在本机复现与更新

网页由 HTML、CSS、JavaScript、路线与房源 JSON、本地底图分块组成，打开页面时读取已发布快照，API key 供本机或 GitHub Actions 的路线重算脚本使用，仓库提供 POI、天气和路径查询 CLI，高德官方 MCP 可以把相同能力作为工具接入支持 MCP 的客户端

git clone https://github.com/mx-pai/dongpan-rent-map.git
cd dongpan-rent-map
python3 scripts/validate.py
python3 scripts/build.py
python3 -m http.server 8000 --directory _site

需要重新测路时，设置环境变量 AMAP_API_KEY，执行 python3 scripts/refresh_routes.py --ids 24 可以重算某个点位，--max-points 0 表示重算所选全部点位，公共房源信息由人工核对原页面后，通过证据导入脚本更新，路线重算保留房源证据

仓库的 Pages 工作流 在 main 分支推送后校验数据、构建静态页面、检查桌面与手机浏览器交互、上传产物并部署，另有手动路线测量工作流，使用仓库 Secret AMAP_API_KEY，产出可下载 JSON 供核对后提交，房源信息日期与路线测量日期分别保留
